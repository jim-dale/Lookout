# Lookout

The contact properties are listed in the official Outlook Interop Assembly documentation here [ContactItem Interface Properties](https://learn.microsoft.com/en-us/dotnet/api/microsoft.office.interop.outlook.contactitem?view=outlook-pia#properties)

## Examples:

```script
lookout list contacts -p FileAs -p FirstName -p LastName -p CompanyName -p HomeTelephoneNumber -p MobileTelephoneNumber
```
